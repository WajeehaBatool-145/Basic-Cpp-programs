## 🔄 C++ Switch-Case Programs
These programs demonstrate decision-making using switch-case statements, including area calculation, currency conversion, day finder, shopping invoice, and basic calculator.

### 🔺 Area Calculator
This program calculates the area of a circle, rectangle, or triangle based on user choice using a switch-case structure.

### 💱 Currency Converter 
This program converts an amount in USD to PKR, INR, or Euros based on user choice using a switch-case structure.

### 📅 Day of the Week Finder
This program displays the name of the day corresponding to a number (1–7) using a switch-case structure.

### 🛍️ Shopping Invoice Generator
This program allows the user to select a category and item, calculates the total price, applies discounts based on amount, and generates a simple invoice using nested switch statements.

### ➕➖ Basic Calculator Using Switch
This program performs addition, subtraction, multiplication, or division based on the user’s choice using a switch-case structure.
