## 🛠️ C++ Functions Programs
These programs demonstrate the use of functions for calculations, greetings, factorial, even-odd checks, and restaurant billing.

### 🧮 Calculator Using Functions
This program performs addition, subtraction, multiplication, and division using separate functions and allows repeated operations with a do-while loop.

### 🔢 Even or Odd Using Function
This program checks whether a given number is even or odd by using a separate function.

### 👋 Greeting Function
This program demonstrates a simple function that prints a welcome message when called.

### 🔢 Factorial Using Function
This program calculates and displays the factorial of a given number using a separate function.

### 📚 C++ Math Library Functions
This program demonstrates the use of C++ library functions like `sqrt`, `abs`, `sin`, `cos`, and `pow` on a user-input number.

### 🧾 Restaurant Billing with Functions
This program calculates a restaurant bill with tax and service charges using functions for menu display and cost calculation.
