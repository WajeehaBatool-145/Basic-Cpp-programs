## 🔁 C++ While Loop Programs
These programs demonstrate the use of while loops for counting, summing numbers, and validating user input.

### 🏦 Simple Banking System
This program simulates a basic banking system allowing users to deposit, withdraw, and check balance repeatedly using a loop and switch-case structure.

### ✖️ Multiplication Table Generator
This program prints the multiplication table of a given number up to a specified limit using a while loop.

### 🔑 Password Verification Using Do-While
This program repeatedly asks the user to enter the password until the correct one is entered, using a do-while loop.

### 🍽️ Restaurant Billing System
This program allows users to order items from breakfast, lunch, or dinner menus, calculates the total bill, and displays it using nested do-while loops and switch statements.

### 🔢 Number Printer Using While Loop
This program prints all numbers from 1 up to a user-specified limit using a while loop.

### ➕ Sum of First Five Numbers
This program calculates and displays the sum of the first five natural numbers using a while loop.

### 🔄 Positive Number Validator
This program repeatedly asks the user to enter a number until a positive number is provided using a while loop.
