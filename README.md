
## 🖥️ C++ Beginner Programs Repository

Welcome to this **C++ Beginner Programs** repository! This branch contains a collection of simple yet essential programs for beginners to learn and practice **basic C++ concepts**, such as conditional statements, loops, arithmetic operations, user input, and more. Each program is designed to help you understand fundamental programming logic and real-life applications in a clear and practical way. 🚀💻

## 🌟 Features

Beginner-friendly C++ programs covering loops, conditions, and arithmetic.

Practical examples like banking, shopping, grading, and calculators.

Clean and structured code for easy learning and modification.



## 📚 Overview of Programs

###  Simple Banking System
A menu-driven program that allows users to **deposit, withdraw, check balance, and exit**. It demonstrates loops, conditional statements, and basic banking operations. 🏦💰

###  Multiplication Table Generator
Generates the multiplication table of a user-entered number up to a specified limit using a `while` loop. Helps practice **loops and arithmetic operations**. ✖️🔢

###  Number Printer
Prints numbers from 1 up to a user-defined limit. A simple **loop control and iteration practice** for beginners. 🔢📋

###  Sum of First Five Natural Numbers
Calculates the sum of the first five natural numbers using a `while` loop. Helps beginners understand **sequential addition and loops**. ➕🔢

###  Positive Number Validator
Ensures the user enters a positive number, repeatedly asking for input until valid. Demonstrates **input validation using loops**. ✅🔢

###  Age Category Classifier
Classifies the user’s age as **child, teenager, or adult** using a ternary operator. Helps practice **conditional logic and nested ternary usage**. 🎯

###  Even or Odd Number Checker
Checks if a user-entered integer is **even or odd** using the modulus operator. Introduces **basic arithmetic and conditional statements**. 🔢⚖️

###  Account Type and Special Offer Checker
Determines account type (low, standard, premium) and special offer eligibility based on balance and loyalty. Helps practice **nested conditions and real-life banking logic**. 💳🎯

###  Bank Withdrawal Balance Checker
Checks if a withdrawal is possible and calculates remaining balance, or shows insufficient funds. Demonstrates **if-else conditions** in a practical scenario. 💰🏦

###  Positive Number Checker
Checks if a number is positive using a simple `if` statement. Good for beginners practicing **basic conditions**. ➕🔢

###  Greatest Number Finder
Finds the **largest of three numbers** using conditional statements. Helps understand **comparisons and decision-making**. 🔢🏆

###  Positive, Negative, or Zero Checker
Determines whether a number is **positive, negative, or zero** using multi-branch `if-else`. Introduces **multi-way decision-making**. ➕➖0️⃣

###  Loan Eligibility Checker
Checks loan eligibility based on **age and income**. Teaches **nested conditions and real-life decision-making**. 💳✅

### Simple Login System
Verifies username and password using `if-else` statements. Helps beginners practice **string comparison and authentication logic**. 🔐💻

###  Role-Based Login System
Authenticates user and provides **role-based access** (Admin, Guest, Anyother). Demonstrates **nested conditions and role-based decision logic**. 🔐👥

###  Temperature Advisory Program
Gives advice based on temperature input (hot, pleasant, or cold). Introduces **multi-branch conditions with practical applications**. 🌡️☀️❄️

###  Scholarship Eligibility Checker
Calculates grades, percentage, and total marks for three subjects, then determines scholarship eligibility. Helps practice **arithmetic and conditional logic**. 🎓🏅

###  Area Calculator Program
Calculates areas of **circle, rectangle, or triangle** based on user choice using `switch`. Helps practice **geometry and conditional branching**. 🔺◼️⚪

###  Currency Converter Program
Converts USD to **PKR, INR, or Euros** using `switch`. Introduces **arithmetic operations and menu-driven programs**. 💵🌍

### Day of the Week Finder
Displays the **day of the week** based on user input (1–7). Demonstrates **switch statements and user input handling**. 📅🗓️

### Shopping Invoice and Discount Calculator
Generates invoices for selected items from **Electronics, Clothing, or Groceries**, applying discounts based on total purchase. Uses **nested switches and arithmetic operations**. 🛒💰

### Basic Calculator Program
Performs **addition, subtraction, multiplication, or division** based on user choice. Teaches **switch statements and arithmetic operations**. ➕➖✖️➗

### Factorial Calculator 🧮
This program calculates the factorial of a number entered by the user. It handles negative numbers by displaying an appropriate message and computes factorials for 0 or positive numbers using a for loop.

### Number Printer 🔢
This program prints all numbers from 0 up to a user-defined limit. It uses a simple for loop to display each number on a new line.

### Array Length Finder 📏
This program calculates the length of a predefined array using the sizeof operator. It then displays the total number of elements in the array.

### Array Reverser 🔄
This program allows the user to input elements into an array and then prints the array in reverse order. It demonstrates dynamic input handling and simple array manipulation.

### Restaurant Billing System 🍽️
This program simulates a restaurant billing system where users can select menu items and quantities through functions. It calculates the subtotal, tax, service charges, and displays the final bill.

### Pointer Example 🖇️
This program demonstrates the use of a pointer to access and modify the value of a variable. It shows how changing the value via the pointer affects the original variable.

### Null Pointer Check ❌🖇️
This program checks whether a pointer is null or points to a valid memory location. It demonstrates safe handling of pointers to avoid undefined behavior.

### Swap Two Numbers Using Pointers 🔁
This program swaps the values of two numbers using pointers. It demonstrates how pointers can directly manipulate the values of variables in memory.
## 📌 Note
These programs are primarily for learning and practice purposes. They help beginners understand C++ fundamentals and build confidence for more advanced projects.
