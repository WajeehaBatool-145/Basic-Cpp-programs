## C++ Calculation Programs🧮 
These programs demonstrate basic calculations in C++, including averaging numbers, computing squared distance, and calculating total bills with sales tax.

### Average Calculation Program 📊
This program calculates and displays the average of three test scores using fixed and setprecision to format the output to two decimal places.

### Squared Distance Calculation 📐
This program calculates the squared distance between two points in 2D space using the distance formula without taking the square root.

### Total Bill Calculator 🛒
This program calculates the subtotal, sales tax, and total amount for multiple items, demonstrating basic arithmetic operations in C++.
