## 💻 C++ Basics Programs

These programs demonstrate fundamental C++ concepts like output, escape sequences, patterns, and tabular data formatting.


### Basic Output Program 🖥️
This program prints welcome messages on the screen to demonstrate simple console output in C++.
### Escape Characters Demonstration 🧾
This program shows how escape characters are used to print quotes, new lines, and file paths correctly in C++.
### Star Pattern Printing ⭐
This program prints a simple star pattern using multiple cout statements to practice basic output formatting in C++.
### Tabular Data Display 🗂️
This program prints a table of items with their price and quantity using \t for proper spacing and alignment in C++.
