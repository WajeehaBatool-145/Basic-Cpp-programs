## 🔁 C++ For Loop Programs
These programs demonstrate the use of for loops for factorial calculation, star patterns, summing numbers, multiplication tables, and number printing.

### 🔢 Factorial Calculator
This program calculates the factorial of a non-negative number using a for loop and handles special cases like 0 or negative input.

### ⭐ Star Pattern Using For Loop
This program prints a 5×5 star pattern using a for loop.

### ➕ Sum of Natural Numbers Using For Loop
This program calculates and displays the sum of the first `n` natural numbers using a for loop.

### ➕ Sum of First Five Numbers Using For Loop
This program calculates and displays the sum of the first five natural numbers using a for loop.

### ✖️ Multiplication Table Using For Loop
This program prints the multiplication table of a given number up to a specified limit using a for loop.

### ⭐ Reverse Star Pattern Using Nested For Loops
This program prints a decreasing star pattern using nested for loops.

### 🔢 Number Printer Using For Loop
This program prints all numbers from 0 up to a user-specified limit using a for loop.
