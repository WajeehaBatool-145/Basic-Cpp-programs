## 🎯 C++ If-Else-If Programs
These programs demonstrate decision-making using if-else-if statements, including positive/negative checks, loan eligibility, login authentication, weather advisory, and scholarship determination.

### ➕➖ Positive, Negative, or Zero Checker
This program checks whether a given integer is positive, negative, or zero using the if-else-if structure.

### 💵 Loan Eligibility Checker (If-Else-If)
This program determines loan eligibility based on age and income using nested if statements to provide detailed feedback.

### 🔐 Login Authentication Program
This program verifies a user’s username and password, granting access if both are correct, using nested if-else statements.

### 🛡️ Role-Based Login System
This program verifies username and password, then provides access based on the user’s role (Admin, Guest, or Other) using nested if-else statements.

### 🌡️ Weather Advisory Program
This program provides advice based on the temperature input in Celsius using if-else-if conditions.

### 🎓 Scholarship Eligibility Checker
This program calculates total marks, percentage, and grades for three subjects, then determines scholarship eligibility based on the results using if-else-if conditions.
