## C++ Conditional Programs ⚡
These programs demonstrate the use of the ternary operator for decision-making, including age classification, even/odd checking, and account type with special offer eligibility.

### Age Category Program 🧮
This program takes the user’s age as input and classifies it as child, teenager, or adult using the conditional (ternary) operator.

### Even or Odd Checker 🔢
This program takes a number from the user and determines whether it is even or odd using the conditional (ternary) operator.

### Account Type & Offer Checker💳 
This program determines the account type based on balance and checks eligibility for a special offer if the user is a loyal customer using the ternary operator.
