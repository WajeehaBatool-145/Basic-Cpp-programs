## 🖥️ C++ If Statement Programs
These programs demonstrate decision-making in C++ using if and nested if-else statements, including age classification, even/odd checking, loan eligibility, traffic signals, and number comparisons.

### 🏦 ATM Withdrawal Simulator
This program checks if a withdrawal amount is less than or equal to the account balance and displays the remaining balance or an insufficient funds message using an if-else statement.

### 💼 Payroll Calculator
This program calculates an employee’s net salary based on grade, experience, bonus, and tax deductions using if-else conditions.

### 📝 Grade Calculator
This program takes a student’s marks as input and displays the corresponding grade (A+, A, B, C, or Fail) using if statements.

### 💰 Loan Eligibility Checker
This program determines loan eligibility based on salary and, if needed, years of experience using nested if-else statements.

### 🚦 Traffic Signal Checker
This program takes the color of a traffic signal as input and displays the corresponding action (Stop, Go, or Slow Down) using if statements.

### 🔢 Even Number Checker
This program checks if a given integer is even and displays a message using an if statement.

### ➕ Positive Number Checker
This program checks if a given integer is positive and displays a message using an if statement.

### 🏆 Greatest of Three Numbers
This program takes three numbers as input and displays the greatest number using if statements.
